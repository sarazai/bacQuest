# BacQuest — Moroccan Baccalaureate Quiz Game

BacQuest is an interactive, gamified 2D educational quiz application designed for Moroccan high school students preparing for their Baccalaureate exams. It combines gamification mechanics with real curriculum subjects to make studying engaging and effective.

## Features
- **Moroccan Bac Curriculum:** Tailored questions for Math, Physics, Philosophy, English, and Life & Earth Sciences.
- **Gamified Gameplay:** Includes Standard Mode with 15-second timer & 3 lives, plus Survival Rush mode.
- **Power-ups & Lifelines:** 50/50 lifelines, time-freeze power-ups, and streak bonuses.
- **Educational Explanations:** Instant micro-lessons and answer clarifications after each attempt.
- **Multi-Language Support:** Full English, Arabic (RTL), and French UI.
